INOX receipt OCR - self-hosted PaddleOCR.js 0.4.2

PaddleOCR SDK and PP-OCRv6_small detection/recognition models: PaddlePaddle,
Apache-2.0. Spanish is included in the unified PP-OCRv6_small model dictionary.
Models are downloaded only during the asset build, with exact size and SHA-256
verification. Full source URLs and hashes are in manifest.json and the repository's
scripts/paddle-assets.json. Model binaries are not committed to the repository.

The SDK's original, integrity-checked standalone worker bundles OpenCV.js 4.10.0
(Apache-2.0), ONNX Runtime Web 1.24.3 (MIT), js-yaml 4.1.1 (MIT), and Clipper 6.4.2
(Boost-1.0, with Tom Wu's JSBN attribution). Its original license comments are
preserved. Runtime WASM must match the embedded ONNX Runtime version; use 1.24.3.
Additional license texts and ONNX third-party notices are in licenses/.
Clipper copyright: Angus Johnson 2010-2017; JavaScript port by Timo (2017).
JSBN copyright: Tom Wu 2003-2005. Its complete notice is retained separately.

The application adapter uses that pinned worker's transport protocol to avoid
initializing a second OpenCV runtime on the main thread. It supplies only same-site
model/runtime URLs, uses CPU WASM with one thread, and terminates the worker on
cancellation. No paid API or remote inference is involved. OCR confidence is an
estimate and financial data always requires human review.
