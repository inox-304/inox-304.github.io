# Base del proyecto

Estructura de sitio estático y patrón de tarjetas/fichas de producto adaptados de [ScrewFast](https://github.com/mearashadowfax/ScrewFast), revisión `5465254282eca989097585fc4132eddca473caeb`, con licencia MIT conservada en `LICENSE-SCREWFAST`.

La adaptación de INOX304 mantiene Astro y la generación estática, y sustituye la interfaz por un diseño específico inspirado en los videos aportados. Se retiraron documentación Starlight, idiomas de demostración, login, newsletter, blog, planes y bibliotecas de animación no necesarias. El catálogo se almacena en TypeScript y las interacciones usan JavaScript del navegador.

Las imágenes de los productos y los textos provienen de los PDF del usuario. El hero de estudio es material visual de presentación, no una ficha de un modelo concreto. Ver `catalog-sources.md` e `image-prompt.md` para trazabilidad.
